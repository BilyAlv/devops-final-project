# DevOps Final Project

Este es un proyecto de demostración para la práctica final de DevOps CI/CD con GitHub.

## Características

- Página web HTML/CSS simple
- Tests unitarios con Jest
- Configuración Docker con Nginx
- Pipeline CI/CD con GitHub Actions
- Despliegue automático en GitHub Pages

## Ejecución local

Para ejecutar el proyecto localmente:

1. Clonar el repositorio
2. Instalar dependencias: `npm install`
3. Ejecutar pruebas: `npm test`
4. Iniciar servidor Docker: `docker-compose up -d`
5. Abrir en navegador: http://localhost:8080
